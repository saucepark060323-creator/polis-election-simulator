# POLIS — 세계 총선 시뮬레이터

한국·해외 국가·가상국가의 총선을 직접 설계하고 플레이하는 브라우저 게임입니다.

## 플레이
GitHub Pages가 활성화되면 다음 주소에서 실행할 수 있습니다:

https://saucepark060323-creator.github.io/polis-election-simulator/

또는 `index.html`을 브라우저에서 직접 열어 실행하세요. 별도의 설치나 서버가 필요하지 않습니다.

## 주요 기능
- 한국, 영국, 독일, 일본, 미국, 프랑스, 가상국가 프리셋
- 국가명·의석수·정당·당색·이념·지역별 지지 기반 편집
- 정책 질문에 답하고 선거운동을 진행하는 방식
- 승자독식, 동트식, 생트라고식 및 혼합형 등 선거제도
- 득표·의석 결과, 의회 의석 시각화, 연정 구성
- 브라우저 자동 저장, JSON 가져오기·내보내기

## GitHub Pages 설정
저장소 **Settings → Pages**에서 **Deploy from a branch**, 브랜치 **main**, 폴더 **/(root)**를 선택하고 저장하세요.

## 안내
각 국가의 기본 설정과 선거 결과는 게임용 가상 데이터입니다. 실제 선거 예측이나 각국 법령의 완전한 재현이 아닙니다.
